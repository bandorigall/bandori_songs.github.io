■ 배경/동기
  뱅드림 전 밴드의 오리지널곡 목록과 (일본어/발음/한국어) 번역 가사를
  밴드별로 한 페이지에 정리. 발매일 순으로 곡을 훑고 가사를 콜/발음까지
  볼 수 있게 하는 게 목표.

■ 구조 진화
  - 초기: convert_html.py 로 CSV→정적 HTML 생성하는 파이프라인.
  - 전환: index.html 이 브라우저에서 CSV/lyrics를 직접 fetch해 렌더하도록
    JS 포팅 → HTML 생성 단계 폐지. 舊 생성기는 legacy/로 이동.
    (곡/가사 추가가 "CSV·txt만 갱신"으로 끝나 운영이 훨씬 가벼워짐)

■ 데이터 원칙(중요 결정)
  - 제목(원어)·발매일·앨범커버·유튜브링크는 반드시 공식 자료로 교차확정.
    · 발매일 = 공식 디스코그래피 発売日 (유튜브 업로드일/팬위키 금지 —
      업로드가 발매 하루 전 선공개인 경우가 있어서).
    · 앨범커버 = 공식 og:image, 릴리스당 1회만.
    · 유튜브 = 공식 오리지널 재생목록. 교차검증은 "영상 ID" 기준
      (PasPare 작업 때 ID 대조로 곡 1개 누락 발견).
  - 제목(한국어): 옛곡은 Bestdori(한도리) 공식 번역, 한섭 종료 이후 추가곡은
    직접 번역. 영어 전용 제목은 한국어 칸 공백(정규식 판정).
  - 오리지널만 수록: Bestdori API tag=="normal" 필터.

■ 가사 크롤러 삽질 기록
  - 나무위키가 Cloudflare로 봇 차단 → WebFetch 403. undetected_chromedriver
    로 우회, 급할 땐 curl + 브라우저 UA.
  - 가사 셀 탐지: <br> 많고 한/일 혼재 td를 고르는 휴리스틱(EXTRACT_JS).
  - 오염 패턴: 나무위키 문서 없는 신곡은 "디스코그래피 틀"을 가사로 오인해
    긁어옴(여러 곡이 정확히 같은 글자수 = 의심 신호). → 캐시 블록 삭제.
  - 동명이곡/오매칭으로 다른 곡 가사가 들어간 사례(예: Game Changer 자리에
    K-pop 가사) → "가사 오류 교정" 절차로 재수집.
  - 전각/반각 함정: Bestdori 전각 ＝ vs 공식 반각 = → 크롤러가 URL 못 잡음.
    공식 표기(반각)로 교정해야 성공.
  - Windows 콘솔 cp949로 일본어 print 중 UnicodeEncodeError로 죽는 문제 →
    PYTHONUTF8=1 PYTHONIOENCODING=utf-8 로 실행.
  - 밴드명 인자 빼면 기본값 morfonica로 돌아 엉뚱한 밴드 오염 → 인자 필수화.
