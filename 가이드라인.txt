================================================================
발매곡목록 CSV 작성 가이드라인 (컬럼별)
================================================================
※ 상세 절차/스크립트/트러블슈팅은 workflow.txt 참고.
※ 이 문서는 "각 컬럼을 무엇으로, 어디서 채우나"의 기준만 정리.

CSV 컬럼 순서(고정):
  TJ번호, 제목(원어), 제목(한국어), 발매일 / 커버일,
  앨범커버, 원곡가수, 곡유형, 링크, 번역가사 링크
  - "발매일 / 커버일" 슬래시 양옆 공백 필수(convert_html.py 인식용)
  - 정렬: 발매일 오름차순
  - TJ번호 컬럼은 현재 대부분 비워둠(노래방 번호 있으면 채우는 용)

----------------------------------------------------------------
① 제목(원어) · 발매일 · 앨범커버 · 링크  → 전부 "공식" 기준
----------------------------------------------------------------
이 네 컬럼은 반드시 뱅드림 공식 자료로만 교차확정.

[제목(원어)]
  - 공식 디스코그래피 표기 그대로. 기호(！?☆×〜“”)·대소문자도 원본대로.
  - 예: Y.O.L.O！！！！！, "Easy come, Easy go！", “Say cheese!!!!!”
    → 쉼표/따옴표 포함 제목은 CSV에서 "..."로 감싸짐(자동)

[링크(유튜브)]
  - 뱅드림 공식 채널의 밴드별 재생목록에서 확보.
    유튜브 검색: "{밴드} original songs" (예: afterglow original songs)
    → 공식이 밴드별 오리지널곡 재생목록을 계속 업데이트해줌.
  - 개별 곡 링크(watch?v=... 또는 youtu.be/...) 형태로 기입.
  - 교차검증은 "영상 ID" 기준(제목 오타·누락 방지). workflow.txt 참고.

[발매일 / 커버일]
  - 공식 디스코그래피 페이지의 "発売日" 기준.
  - 팬위키 날짜·유튜브 업로드일 쓰지 말 것(업로드가 발매 하루 전 선공개인 경우 있음).
  - 같은 싱글/앨범 수록곡은 같은 발매일 공유.

[앨범커버]
  - 공식 디스코그래피 og:image URL만 사용(bang-dream.com / en.bang-dream.com).
    googleusercontent 등 비공식 금지.
  - 같은 릴리스(싱글 A면+커플링/앨범 수록곡)는 같은 자켓 URL 공유.
  - 디지털 싱글 등 단독 페이지 없으면 수록 앨범 자켓으로 대체.
  - 최신곡이 Apple Music(mzstatic) 자켓인 경우도 있으나, 가능하면 공식 우선.

----------------------------------------------------------------
② 제목(한국어)
----------------------------------------------------------------
  - 원어가 "영어 전용"(한글·가나·한자 없음)이면 → 비운다.
    예: True Color, Scarlet Sky, COMIC PANIC!!!, IGNITE GLOW …
  - 원어에 일본어/한자 포함 → 한국어 제목을 채운다.
  - 채우는 출처 우선순위:
    1) 옛날곡: Bestdori(한도리)의 한국 공식 번역 제목 사용.
    2) 2024년 2월 이후(≈Bestdori 한섭 이후) 추가곡은 공식 번역이 없을 수 있음
       → 직접 번역하거나 검색해서 채움.
  - 예: ツナグ、ソラモヨウ→이어진 하늘 모양, サクラゼンセン→벚꽃 전선,
        燦々→산산(찬란), 極彩色→극채색

----------------------------------------------------------------
③ 원곡가수 · 곡유형
----------------------------------------------------------------
[곡유형] = {오리지널, 커버, 타이업} 셋 중 하나.

[원곡가수] 곡유형별 기입 규칙:
  - 오리지널 → 해당 밴드명 (예: Afterglow)
  - 커버     → 원곡의 원 아티스트를 찾아서 기입
  - 타이업   → 타이업 상대 아티스트를 함께 기입
                예: 燦々(じん 타이업) → 원곡가수 "じん", 곡유형 "타이업"
  - 합작/콜라보곡은 " · "로 아티스트 나열
    예: competition곡 "Roselia · Afterglow", CiRCLE THANKS MUSiC♪는 7밴드 나열

----------------------------------------------------------------
④ 번역가사 링크
----------------------------------------------------------------
  - 기본은 모르포니카(morfonica) 가사 워크플로우 절차대로.
    → workflow.txt "가사 수집 / 가사 오류 교정" 섹션 참고.
  - 보통 나무위키 곡 문서 URL이 들어감(namu.wiki/w/...).
  - 나무위키에 번역 없으면 디시 번역/직접 생성 후 출처 URL 기입,
    lyrics/제목(원어).txt 수동 작성.
  - 절차 요약:
    1) python lyrics_collector.py {밴드}   (★밴드명 인자 필수)
    2) PYTHONUTF8=1 PYTHONIOENCODING=utf-8 python cache_to_files.py {밴드}
    → index.html이 CSV/lyrics를 직접 읽으므로 HTML 재생성 불필요.

----------------------------------------------------------------
신곡 추가 시 요약 순서
----------------------------------------------------------------
  1. 공식 재생목록/디스코그래피에서 ①(제목원어·발매일·커버·링크) 확정 후 행 추가
  2. ②제목(한국어): Bestdori 또는 직접 번역(영어전용이면 공백)
  3. ③원곡가수·곡유형 기입
  4. ④가사: lyrics_collector → cache_to_files (morfonica 워크플로우)
  5. 발매일 오름차순 정렬 확인

================================================================
실전 팁 (밴드 리스트 대량 작성 경험 정리)
================================================================
※ 하로하피 40곡 채우며 실제로 막혔던/유용했던 것들.

[ 곡 목록 뽑기 — Bestdori API가 가장 효율적 ]
  - 전곡 메타(제목 JP/KR, 커버여부)를 한 방에:
      곡: https://bestdori.com/api/songs/all.5.json
      밴드: https://bestdori.com/api/bands/all.1.json
    각 곡 객체: bandId, tag, musicTitle[0]=일본어/[4]=한국어, jacketImage
  - 밴드ID 예: Poppin=1, Afterglow=2, 헬로해피=3, PasPare=4,
    Roselia=5, Morfonica=21, MyGO=45, AveMujica=46 (bands API로 확인)
  - ★ tag == "normal" → 오리지널 / tag == "anime" → 커버.
    발매곡목록 CSV는 (다른 밴드 CSV 전례상) 오리지널만 담는다.
    → bandId==N & tag=="normal" 필터가 곧 그 밴드 오리지널 전곡.
  - ★★ Bestdori publishedAt은 "게임 수록일"이라 CD 발매일과 다름.
    발매일은 절대 Bestdori로 쓰지 말 것 → 공식 디스코그래피 発売日.

[ 발매일 — 공식 우선순위 ]
  - CD/디지털 있는 곡: 공식 디스코그래피 発売日.
  - 게임 전용 이벤트곡(CD 없음)만 Bestdori publishedAt = 사실상 발매일.
  - 유튜브 MV 업로드일은 발매일 아님(선공개/후행 있음). 쓰지 말 것.

[ 유튜브 링크 — 공식 재생목록 ID로 일괄 ]
  - 밴드 공식 오리지널 재생목록(예: PLkc6qZ_s5R1... 계열)에서 추출:
      PYTHONUTF8=1 yt-dlp --flat-playlist --no-warnings \
        --print "%(id)s\t%(title)s" "[재생목록URL]"
  - 재생목록이 안 잡히면 유튜브에 "{밴드} original songs" 검색.
    단 게임 채보(가루파 [Expert] #NNN …歌詞付き) 재생목록은 커버 섞이고
    공식 MV 아님 → 오리지널 MV 재생목록과 혼동 금지.
  - 게임 전용 최신곡은 아직 MV 없을 수 있음 → 링크 칸 비움(정상).

[ 앨범커버 — 릴리스 단위로 og:image 1번만 ]
  - 공식 디스코그래피 페이지 ID는 구글 검색이 빠름(인덱스는 JS라 curl 무용):
      "[릴리스명] {밴드} discographies" → bang-dream.com/discographies/{ID}
  - og:image 추출:
      curl -sL -A "Mozilla/5.0 ... Chrome/120 ..." \
        "https://bang-dream.com/discographies/{ID}" \
      | grep -oE 'og:image" content="[^"]+"'
  - 같은 싱글/앨범 수록곡은 같은 자켓 공유 → 릴리스당 1번만 조회.
  - 디지털 싱글(단독 페이지 無)은 수록 앨범 자켓으로 대체(가이드 원칙).
  - 게임 전용곡(공식 CD자켓 없음)만 Bestdori 인게임 자켓 허용:
      https://bestdori.com/assets/jp/musicjacket/musicjacket{G}_rip/
      assets-star-forassetbundle-startapp-musicjacket-musicjacket{G}-{jacketImage}-jacket.png
    여기서 G = ceil(musicId/10)*10 (예: 748→750, 773→780, 800→800).
    Content-Type: image/png 로 살아있는지 확인(text/html이면 그룹 틀림).

[ 제목 표기 함정 ]
  - Bestdori 제목이 전각/특수기호를 쓰는 경우가 있음.
    예: にこ×にこ＝ハイパー… (Bestdori는 전각 ＝) vs 공식·나무위키는 반각 =.
    → 나무위키 크롤러가 URL 못 잡고 실패함. 공식(유튜브 재생목록/아마존)
      표기를 기준으로 반각으로 교정해야 lyrics_collector가 성공.
  - 영어전용 판정(제목 한국어 공백)은 한글·가나·한자 유무로.
    YAPPY！SCHOOL CARNIVAL☆彡 처럼 전각기호만 있고 가나 없으면 → 공백.

[ 가사 크롤러 실패/오염 패턴 ]
  - 나무위키 문서 없는 신곡은 크롤러가 "디스코그래피 틀"을 가사로 오인해
    긁어옴(여러 곡이 정확히 같은 글자수 = 의심 신호. 하로하피는 1688자).
    → cache에서 해당 블록 삭제, CSV 번역가사 링크 비움.
  - lyrics_collector 재실행 시 캐시에 없는 곡만 재시도하지만, 위 오염곡도
    다시 긁으므로 재실행 후 다시 삭제 필요.
  - 나무위키에 없을 때 다른 출처(경험상 유효했던 순):
      1) utaten.com  ← 후리가나 포함 전문(全文), 스크랩 잘 됨(강력 추천)
      2) petitlyrics ← 검색은 되나 뒷부분이 canvas(이미지)라 잘림 주의
      3) uta-net     ← 아티스트 페이지 /artist/{id}/ 에 전곡 인라인
      4) 더위키/miraheze/fandom ← 봇차단·가사표 없음 많음(비추)
  - 어디에도 원문 없는 최신 게임곡은 지어내지 말 것.
    링크 비운 채 두고, 나중에 나무위키 생기면 크롤러 재실행으로 채움.

[ 수동 가사 파일 형식(재확인) ]
  - lyrics/제목(원어).txt : 블록당 3줄(일본어 / 발음(한글) / 한국어),
    블록 사이 빈 줄. 반복 후렴도 실제 음원 순서대로 전부 기재.
  - 파일명은 CSV 제목(원어)와 100% 일치(전각기호 포함).
